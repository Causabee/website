# causabee.app

The website of [Causabee](https://causabee.app), served by GitHub Pages from `site/`.

Causabee's app is not open source. How it hides names before any text leaves the device is: [github.com/causabee/disguise](https://github.com/causabee/disguise). Problems and ideas go to that repository's issues.

This repository is published from the app's own repository; changes made here directly are overwritten.
